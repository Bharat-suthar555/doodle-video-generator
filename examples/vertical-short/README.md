# Example: The Two-Minute Rule

A 21-second, 1080x1920 vertical explainer for Shorts and Reels: a hook with icons and a marker highlight, a column flowchart with a diamond decision and labeled branches, and a payoff scene.

```bash
doodle-video-generator validate storyboard.json
doodle-video-generator build storyboard.json
```

Content stays above the bottom quarter of the frame, where captions and platform buttons appear. The narration is generated and has no audio, so caption timing is estimated.
